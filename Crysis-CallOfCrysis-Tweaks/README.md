# Crysis Remastered - Nanosuit Gameplay Tweaks

This mod adjusts player physics and Nanosuit balance parameters to enhance responsiveness and speed, making you feel more like a super soldier.

## Features

- **Nanosuit Adjustments:** Speed mode sprint, energy multipliers, armor health values, and extra jump force in view directions are rebalanced.
- **Improved Movement:** Adjusts default multipliers to allow more agile scaling and fluid movement.

## Installation

1. Copy `zzzz_zRemasterGameplayTweaks.pak` into your `...\Crysis Remastered\Game\` folder.
